# wlogout-theme
A css file of wlogout which I think is good

Please copy the style.css file and the layout file to ~/.config/wlogout/
<br>And start the wlogout with command:
<br>wlogout --protocol layer-shell -b 5

For icons, please find them your selves（Due to copyright reasons） and put it in /usr/share/wlogout/icons
<br>you need to rename them

or you can do 
<br> cp -r /usr/share/wlogout/icons ~/.config/wlogout/icons
<br>or
<br> cp -r /usr/share/wlogout/assests ~/.config/wlogout/icons
<br>for using the deafult icons
